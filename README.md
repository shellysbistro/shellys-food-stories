# Shelly's Food Stories Dashboard

An interactive, responsive prototype for the St. James-Assiniboia School Division Universal Nutrition Program.

## Open the dashboard

Open `index.html` in a browser, or run any local static server in this folder.

No package installation or build step is required.

## Included

- 45-item source menu inventory
- 16 grouped food stories
- Six source-linked, interactive food-history comic chapters
- Original food-character and four-panel history illustrations
- Clue challenges, story stamps and saved passport progress
- K–3, Grades 4–6 and Grades 7–12 reading levels
- Search and cultural/geographic filters
- Ingredient farm-to-school journeys
- Interactive food map
- Teacher prompt generator and printable lesson view
- Discussion-card deck
- Five-layer recommended school package
- 25-deliverable coverage overview

## Content note

This is an educational concept based on the supplied Shelly's Food Stories brief. Before public release, item ingredients and allergen designations must be checked against the current approved Shelly's menu. Historical source labels should also be converted into a final reviewed citation register with publication-ready links.

The comic chapters currently link to source material from Parks Canada, the Louis Riel Institute/Virtual Museum of Métis History and Culture, Smithsonian, Turismo Roma and Université Laval's IREPI.

## Brand note

The visual system is provisional. It uses a warm, botanical-inspired school-food direction without redrawing or imitating an unsupplied Shelly's logo. The food imagery is original educational illustration and is explicitly labelled as such in the interface. Replace or supplement it with real Shelly's food photography when approved photography is available.
